# Frontend - Personal Finance Tracker

This directory is dedicated to the user interface for the Personal Finance Tracker application.

## Options for Frontend:
1. **Lightweight Dashboard**: Use the included modern vanilla HTML5 / CSS3 / JavaScript dashboard for instant browser viewing without dependencies.
2. **React / Next.js / Vite SPA**: Initialize a React or Vite single page application with:
   ```bash
   npx -y create-vite@latest ./ --template react
   npm install
   npm run dev
   ```

## Connecting to Backend:
The frontend connects to the backend API at `http://localhost:8000`.
Check the Swagger docs at `http://localhost:8000/docs` for the interactive API specification.
